# Suggestions — visual style reference and comparable titles

Reference notes captured 2026-11-09 from a photograph of a Chajoy billboard advertisement.

Not a build input. Nothing in this file overrides `prd.md`, and the IP boundary in PRD §9 still
applies in full: the source brand's wordmark, its penguin characters, the green-field plus
pastel-blue machinery palette, and the orchard -> fountain -> stall arrangement must not be
reproduced in *Little Batch Works*. Read the style terms below as a mood target only, never as an
art-direction spec to trace.

## The artwork

The billboard artwork is an isometric 2.5D vector illustration with a clean, cute, pastel
aesthetic. It shows minimalist penguin characters working in a colorful factory/town layout.

## Comparable titles

If you want a story-based strategy, colony manager, or simulation game in this visual style:

### 1. Isometric colony managers and tycoons

- **Two Point Campus / Two Point Hospital** — a bright, clean isometric look where you manage a
  wacky campus or hospital filled with animated little characters running around.
- **Let's Build a Zoo** — a cute isometric management game where you design a zoo, breed animals
  (including crazy hybrids), and make narrative moral choices about how you run the business.
- **Parkitect** — a polished theme-park tycoon with a crisp, vector-like isometric aesthetic close
  to the factory layout in the image.

### 2. Cozy narrative builders

- **Bear & Breakfast** — a laid-back management RPG where you play a well-meaning bear running a
  B&B in the woods, with a clean 2D vector cartoon style.
- **Littlewood** — a relaxing town-building game set after the world has already been saved; a
  grid-based layout with heavy focus on relationships with townsfolk.

## Style keywords for our own art

Terms to look up when describing the look we are aiming for:

- **Isometric vector art** — creates the pseudo-3D, grid-based perspective.
- **Chibi / kawaii character design** — the round, minimalist character style on the billboard.
- **Flat design / clean line art** — thick distinct outlines with smooth gradients or solid pastel
  fills.
